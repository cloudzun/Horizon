## [清理 SVG 文件面临的复杂安全挑战](https://muffin.ink/blog/scratch-svg-sanitization/) ⭐️ 8.0/10

**背景**: Scalable Vector Graphics (SVG) 是一种基于 XML 的图像格式，支持脚本执行、样式定义和外部资源加载，这在渲染不受信任的内容时引入了安全风险。传统的清理方法通常依赖正则表达式或 DOM 解析来剥离恶意标签，但面对混淆载荷或浏览器特定的解析差异时往往失效。现代 Web 安全标准正逐渐转向浏览器原生 API 和严格的策略执行，以缓解这些风险。
