## [苹果修复允许恢复已删除聊天消息的 iOS 漏洞](https://techcrunch.com/2026/04/22/apple-fixes-bug-that-cops-used-to-extract-deleted-chat-messages-from-iphones/) ⭐️ 8.0/10

苹果已修补一个特定的 iOS 漏洞，该漏洞允许执法机构从扣押设备的通知缓存中恢复已删除的聊天消息。此修复解决了一个缺陷，即即使相关应用程序被删除，消息内容仍保留在操作系统的数据库中。 此次更新通过关闭削弱 Signal 等消息应用程序端到端加密预期的漏洞，对数字取证和用户隐私产生了重大影响。它突出了移动操作系统内超出单个应用程序安全协议的数据残留带来的更广泛挑战。 该漏洞存在是因为 iOS 将解密的通知文本存储在本地数据库中，而在删除应用程序时并未清除该数据库。用户可以通过配置通知设置仅显示不含消息内容的通用警报来降低类似风险。

## [研究人员发现 Firefox IndexedDB 漏洞可关联 Tor 身份](https://fingerprint.com/blog/firefox-tor-indexeddb-privacy-vulnerability/) ⭐️ 8.0/10

研究人员发现 Firefox IndexedDB 实现中存在一个漏洞，该漏洞会生成一个稳定的标识符，并在不同的 Tor Browser 身份之间持久存在。即使人们尝试使用 Tor 的隐私功能隔离会话，此漏洞也允许网站对用户进行指纹识别。 这一发现破坏了 Tor Browser 的匿名性保证，使得在不使用 Cookie 或 IP 地址的情况下进行跨会话跟踪成为可能。它对依赖 Tor 进行身份分离的高风险用户（如在需要严格隔离的威胁模型下工作的记者或活动人士）产生重大影响。 只要 Firefox 进程保持运行，该标识符就会持续存在，这意味着用户必须在不同的身份之间完全退出 Tor Browser 以降低风险。与传统的 Cookie 不同，这种跟踪方法利用了通常无需用户明确许可即可使用的浏览器存储 API。

hackernews · Lobsters · Apr 22, 17:35

**背景**: IndexedDB 是由 W3C 维护的 JavaScript API，允许 Web 浏览器在本地存储大量结构化数据。浏览器指纹识别是一种收集设备信息的技术，即使 Cookie 等标准跟踪方法被阻止，也能识别用户。Tor Browser 基于 Firefox 构建，旨在通过将浏览活动隔离到单独的身份中来防止此类跟踪。
