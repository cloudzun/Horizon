## [Datasette 用 Sec-Fetch-Site 头保护取代 CSRF 令牌](https://simonwillison.net/2026/Apr/14/replace-token-based-csrf/#atom-everything) ⭐️ 8.0/10

Datasette PR #2689 实现了基于 Sec-Fetch-Site 头的 CSRF 保护，取代了 asgi-csrf 库中使用的传统令牌方法。此更改从模板中移除了所有隐藏的 CSRF 令牌输入，并消除了 skip_csrf 插件钩子。 这减少了开发者的摩擦同时保持安全性，遵循了 Filippo Valsorda 的研究，该研究也被 Go 1.25 采用。它代表了行业向更简单、更难绕过的基于头的 Web 安全实践的更广泛转变。 Sec-Fetch-Site 头无法被 JavaScript 伪造，因为 Sec- 前缀是浏览器强制执行的禁止头名称。升级指南记录了 CSRF 更改，文档已更新以描述新的基于头的方法。

rss · Simon Willison · Apr 14, 23:58

**背景**: CSRF（跨站请求伪造）攻击诱骗已认证用户向 Web 应用程序提交意外请求。传统保护使用嵌入表单中的令牌，必须与服务器期望匹配。Fetch Metadata 头（如 Sec-Fetch-Site）提供源上下文，服务器可用于拒绝跨源请求而无需令牌。

## [AI 安全审计变为计算支出的经济函数](https://simonwillison.net/2026/Apr/14/cybersecurity-proof-of-work/#atom-everything) ⭐️ 8.0/10

英国 AI 安全研究所确认 Anthropic 的 Claude Mythos Preview 随着消耗的计算 token 增加能发现更多安全漏洞。Drew Breunig 强调这创造了一种类似 Proof of Work 的动态，即安全性取决于在 token 消耗上超过攻击者。 这一转变将网络安全转化为直接的经济竞争，防御可行性依赖于扩展计算资源而不仅仅是算法改进。这表明开源库可能会增值，因为对其的安全投资可以共享给所有用户。 该分析依赖于 AISI 的独立评估，显示 Claude Mythos 中 token 支出与漏洞发现率之间存在线性相关性。因此，加固系统需要比攻击者利用漏洞花费更多的 token 来发现漏洞。

rss · Simon Willison · Apr 14, 19:41

**背景**: Proof of Work 是比特币等区块链系统中使用的共识机制，通过计算努力和能源支出来维持安全性。Claude Mythos 是截至 2026 年 4 月 Anthropic 未发布的前沿模型，以其在编码和网络安全基准测试上的卓越性能而闻名。这一概念将加密安全经济学与漏洞检测中新兴的 AI 扩展定律联系起来。

## [倡导 Rust 实现稳定的尾调用优化](https://trifectatech.org/blog/tail-calls-project-goal/) ⭐️ 7.0/10

一项新提案倡导将稳定的尾调用优化确立为 Rust 编程语言内的正式项目目标。该倡议旨在解决 Rust 目前缺乏对尾递归函数保证优化的问题。 尾调用优化对于 Rust 的系统编程至关重要，因为它影响栈安全性并能实现高效递归而不会导致栈溢出。实现这一点将使 Rust 更符合函数式编程标准，并提高特定算法模式的性能。 该提案强调尾调用可以在不添加新栈帧的情况下实现，类似于 goto 语句。目前，Rust 开发者通常依赖手动循环转换来避免栈深度问题。

rss · Lobsters · Apr 14, 11:04

**背景**: 尾调用优化允许作为过程最终动作执行的子程序调用重用当前栈帧。这防止了递归期间调用栈无限增长，这在 Scheme 等功能性语言中通常是有保证的。如果没有这种优化，深度递归可能导致系统编程中的栈溢出错误。
